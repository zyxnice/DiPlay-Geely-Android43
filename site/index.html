星越 2019 款
8600 车机 CarPlay

独立维护的 DiPlay Android 4.3 / API18 适配项目，仅服务吉利星越 2019 款 8600 原厂车机。当前优先 USB CarPlay，USB 验收通过后优先推进车机 HUD 适配，无线连接列入后续规划。

查看本项目发布包 ↓安装与连接

仅支持星越 2019 款 8600；其他车型、年份或车机版本不在支持范围。

已记录环境：GEELY NL5QJ / C3ALFUS，固件 06.03.08600.H53.00060。其他固件需独立验证，安装前请核对完整版本。

专用范围：吉利星越 2019 款、8600 版本原厂车机。博瑞 H52、BYD、其他吉利车型及通用 Android 车机不在支持范围。

01

安装到目标车机

  1. 停车后核对车型、年份、8600 版本及完整固件号。
  2. 从本仓库 Releases 选择明确标注星越 8600 的包，并阅读校验值、限制与回退说明；没有匹配包时不要改用上游或 H52 包。
  3. 保留当前可用 APK 与设置。安装到车机，按实际提示授予权限；覆盖安装要求相同包名和签名。
  4. 使用支持数据传输的 USB 线连接已解锁 iPhone，选择 USB 连接入口并按实际提示完成授权。

充电不代表数据连接成功。驱动解绑和系统 USB 模式切换属于特定现场维护步骤，不是通用安装流程。

02

当前验证状态

  • 8600 实车已建立 USB CarPlay 连接，有画面、触控和声音可用的现场反馈。
  • main 保留 USB3-B-output1 基线；音乐改善有车测反馈，画面连续性与整体流畅度仍未完成验收。
  • 后续诊断包、本地未提交改动和模拟测试不等于已发布或通过实车验收。
  • 无线、5GHz、方向盘按键及免 root 全场景不作已通过承诺。
  • 推进顺序：当前优先 USB；USB 方案验收通过后优先推进车机 HUD 适配；后续适配无线连接方案。规划不代表功能已实现或验收通过。
  • 博瑞 H52/P21/P22 和原上游结果仅作历史参考，不是本车的兼容或验收依据。
