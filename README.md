# DiPlay · 吉利星越 2019 款 8600 车机专用

本项目仅面向**吉利星越 2019 款、8600 版本原厂车机**，维护 Android 4.3 / API18 环境下的 CarPlay 适配，当前重点为 USB 连接、音视频播放、触控响应与连接恢复。

仓库已脱离原上游独立维护。博瑞 H52、其他吉利车型、其他年份或车机版本、BYD 及通用 Android 车机均不在本项目支持范围内。即使系统版本相同，也不能据此认定兼容。

## 适用范围

| 项目 | 当前范围 |
| --- | --- |
| 车型 | 吉利星越 2019 款 |
| 车机版本 | 8600 |
| 已记录硬件 | GEELY NL5QJ，BOARD=C3ALFUS |
| 已记录固件 | `06.03.08600.H53.00060` |
| 系统 | Android 4.3 / API18 |
| 当前适配重点 | USB CarPlay、音视频、触控与重连 |
| 车测应用包名 | `com.shihab.diplay.repair1.geely8600` |

上述硬件与固件来自已有现场记录，不代表所有标为 8600 的固件均已验证。请先核对车型、年份、车机和完整固件号。

## 当前状态

- 8600 实车已经建立 USB CarPlay 连接，现场记录包含画面、触控和声音可用的反馈。
- 当前 `main` 保留 USB3-B-output1 基线；音乐效果改善已有车测反馈，画面连续性与整体流畅度仍未完成验收。
- 后续诊断包、本地未提交改动和模拟测试结果，不等于已合入主分支、正式发布或通过实车验收。
- 无线连接、5GHz、方向盘按键及免 root 全场景不作已通过承诺；旧 H52/P21 的结果不适用于本车。

## 后续规划与优先级

1. **当前优先 USB**：先完成 USB CarPlay 的连接、音视频、触控及恢复验证，推进现有流畅度问题闭环。
2. **USB 方案验收通过后，优先推进车机 HUD 适配**：先核对星越 2019 款 8600 的 HUD 接口与可用数据，再进行适配和实车验证；旧 BYD/H52 实现不代表本车已支持。
3. **后续适配无线连接方案**：无线 CarPlay 属于本项目未来规划，具体连接方式与频段在方案核验后确定，当前不承诺已可用或上线时间。
